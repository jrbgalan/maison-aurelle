# AGENTS.md

## Project Context

This is a modern Next.js project for Maison Aurelle, an atelier of luminous restraint.
The application is independently authored and maintained with Next.js App Router, Tailwind CSS, Framer Motion, and OpenAI.

## Key Files

- `src/app/`: Next.js App Router pages and API routes.
- `src/components/`: Reusable UI, layout, chat, and presentation components.
- `src/data/`: Data models and curated content (services, specialists, journal, gallery).
- `.env.local`: Environment variables (OpenAI API key, Unsplash API key).

## Development Workflow

- Run `npm run dev` to start the Next.js development server on `http://localhost:3000`.
- Run `npm run build` to verify production compilation.
- Run `npm run lint` for code quality checks.
